# Demo Automio · Vicmatic

Demo del panel de pedidos a proveedores: lectura del estado de cada pedido en los portales de los proveedores (con el acceso del cliente), seguimiento y reclamaciones automáticas según reglas configurables (primera reclamación por retraso, escalado a la segunda si no hay respuesta, recordatorio preventivo ante riesgo de retraso).

Todos los datos (portales, proveedores, pedidos, fechas, reclamaciones y correos) son ficticios, con aviso visible en la propia demo. No está conectada a ningún portal real ni envía nada.

## Archivos

- `index.html`: la demo completa (abrir en cualquier navegador)
- `logo.svg`: logotipo de Vicmatic, extraído de vicmatic.com para la demo
